# Gerador de Tabuada

Um projeto simples e funcional para gerar tabuadas de forma rápida e dinâmica. Basta inserir um número, definir até onde deseja calcular, e o sistema exibirá automaticamente todos os resultados organizados na tela.

## 🚀 Funcionalidades

* Geração de tabuada baseada em qualquer número informado.
* Possibilidade de escolher até qual número multiplicar.
* Exibição automática e organizada dos resultados.
* Layout responsivo e moderno.
* Código simples, ideal para estudos de **HTML, CSS e JavaScript**.

## 🧠 Como funciona

O usuário preenche dois campos:

1. **Tabuada do:** número base.
2. **Multiplicar até:** limite da multiplicação.

Ao clicar em **Calcular**, o JavaScript cria automaticamente as linhas da tabuada usando DOM e exibe no elemento de resultados.
